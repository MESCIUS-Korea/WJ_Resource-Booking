# Resource Booking — 자원 예약 데모

React + JavaScript + **Wijmo FlexScheduler**(5.20262.60)로 만든 샘플 프로젝트입니다.
서버·DB·로그인 없이 **브라우저 메모리에서만** 동작하며, 새로고침하면 초기 데이터로 돌아갑니다.

## 데모 소개

### 개요

설비·회의실·작업자처럼 **동시에 한 건만 사용할 수 있는 자원**을 예약하는 샘플입니다. 예약을 만들거나 옮길 때마다 충돌을 검사하고, 그 사유를 안내합니다.

Wijmo FlexScheduler를 자원별 타임라인으로 구성하는 방법과, 스케줄러 바깥의 업무 규칙(충돌·승인·권한)을 React 앱에서 처리하는 방법을 함께 보여 줍니다.

### 주요 시나리오

| 시나리오       | 동작                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| 시간 충돌      | 등록·수정·드래그 이동 시 저장 전에 충돌을 안내하고, 충돌한 예약을 표시                                      |
| 대안 제안      | 같은 자원의 다른 시간, 또는 같은 시간에 쓸 수 있는 다른 자원을 제안                                         |
| 승인 필요 자원 | 일반 사용자의 확정 신청은 가예약(승인 대기)으로 등록되고, 관리자가 승인하면 확정                            |
| 가예약         | 유지 시간이 지나면 자동 해제. 관리자는 가예약을 밀어내고 예약 가능                                          |
| 반복·묶음 예약 | 일·주·월 단위 반복과 다중 자원 동시 예약(예: 설비 + 작업자). 일부 회차만 충돌하면 해당 회차를 제외하고 저장 |
| 취소 예약      | 자원을 점유하지 않아 같은 시간에 다른 예약 등록 가능. 겹치면 한 칸을 위아래로 나눠 표시                     |

### 예약 상태

| 상태   | 의미                                              | 충돌 검사            |
| ------ | ------------------------------------------------- | -------------------- |
| 확정   | 사용이 확정된 예약                                | 대상                 |
| 가예약 | 승인 대기 또는 임시 확보. 시간이 지나면 자동 해제 | 대상 (밀어내기 가능) |
| 취소   | 기록은 남고 자원은 비워짐                         | 제외                 |

삭제는 취소와 다릅니다. 삭제하면 원본에서 제거되며, 직후에는 되돌리기로 복원할 수 있습니다.

### 역할과 권한

상단의 역할 전환 버튼으로 일반 사용자와 관리자의 권한 차이를 확인합니다. 실제 인증이 아닌 데모용 전환이며, 예약자 이름도 가상의 표시명입니다.

| 기능                     | 일반 사용자      | 관리자          |
| ------------------------ | ---------------- | --------------- |
| 예약 등록·수정·취소·삭제 | 가능             | 가능            |
| 승인 필요 자원           | 가예약으로 등록  | 승인(확정) 가능 |
| 가예약 밀어내기          | 불가             | 가능            |
| 차단 관리 · 정책 설정    | 잠금 표시와 안내 | 가능            |

### 화면 구성

| 영역         | 내용                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------- |
| 일정 탭      | KPI 카드, 확인 필요 예약 목록, 필터 바, 스케줄러, 상세 패널                                         |
| 대시보드 탭  | 자원별 이용률과 확정·가예약 비율 차트                                                               |
| 변경 이력 탭 | 등록·수정·취소·충돌 거부·정책 변경 기록                                                             |
| 상단 바      | 역할 전환, 되돌리기·다시 실행, 차단 관리, 정책 설정, 내보내기(CSV·ICS·인쇄), 샘플 초기화, 예약 등록 |

스케줄러 조작은 다음과 같습니다.

- **뷰:** 일간(자원별 타임라인), 주간, 월간
- **일정:** 클릭 = 상세, 더블클릭 = 수정, 우클릭 = 메뉴
- **빈 셀:** 더블클릭 = 예약 등록
- **필터:** 유형·자원·예약자·상태·기간을 선택한 뒤 **조회**를 눌러 적용

### 샘플 데이터

- **자원:** 설비(CNC 가공기, 조립 라인, 검사 장비), 회의실(회의실 A·B, 대회의실), 작업자(운전원, 정비 기사)
- **초기 예약:** 확정·가예약·취소가 섞여 있어 처음부터 상태별 표시와 충돌을 확인할 수 있습니다.
- **정책:** 완충 시간·가예약 유지 시간·최대 반복 횟수는 관리자의 **정책 설정**에서 변경합니다. 기본값은 `src/domain/constants.js`의 `DEFAULT_RULES`에 있습니다.

### 시연 순서

1. **충돌 확인:** 기존 예약과 겹치는 시간으로 **예약 등록**을 열면 저장 전에 충돌 안내와 대안이 표시됩니다.
2. **드래그 이동:** 일정을 겹치는 시간이나 다른 자원으로 끌어 놓으면 이동이 거부되고 충돌 예약이 깜빡입니다.
3. **묶음 예약:** **반복·묶음** 영역에서 설비와 작업자를 함께 선택합니다. 한 자원이라도 충돌하면 해당 회차 전체가 실패합니다.
4. **승인 흐름:** 일반 사용자로 승인 필요 자원을 확정 신청해 가예약이 되는 것을 확인한 뒤, 관리자로 전환해 승인합니다.
5. **되돌리기:** **되돌리기**로 직전 변경을 취소하고 **변경 이력** 탭에서 기록을 확인합니다.
6. **내보내기:** 필터를 건 상태에서 CSV·ICS를 내려받으면 현재 필터에 표시된 예약만 포함됩니다.

### 범위

데모 목적상 다음은 포함하지 않습니다.

- 서버·DB 저장 (새로고침 시 초기화)
- 실제 로그인과 계정별 권한
- 알림(이메일·푸시), 외부 캘린더 연동 (ICS 내보내기만 지원)

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
```

## 폴더 구조

```
index.html          진입 페이지 (/src/main.jsx 로드)
package.json
vite.config.js
src/
  main.jsx          앱 시작점 (한국어 문화권, Wijmo CSS, 라이선스 키)
  App.jsx           화면 조립
  styles.css        브랜드 색·폰트·Wijmo 스타일 덮어쓰기
  domain/           규칙·충돌 엔진·저장소·분석·내보내기 (React 무관)
  scheduler/        FlexScheduler 구성(뷰·템플릿·메뉴)과 React 어댑터
  wj/               Wijmo 컨트롤(입력·차트·그리드·탭)의 React 래퍼
  components/       화면 컴포넌트 (폼·패널·모달·탭 내용)
  utils/            파일 내려받기
```
